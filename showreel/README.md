# CLAUDE — Motion Design Showreel 2026

15秒 / 1920×1080 / 60fps / 128BPM のモーショングラフィックス・ショーリール。
映像も音もすべてコードで生成しています（素材ファイルはフォントのみ）。

- `showreel.mp4` — 完成版（H.264 + AAC、4サブフレームのモーションブラー付き）
- `index.html` — ブラウザ上のリアルタイム・プレイヤー（再生・スクラブ可）
- `reel.js` — 映像。全フレームが時間 `t` の純粋関数 `Reel.draw(t)`
- `audio.js` — サウンドトラック。WebAudio で合成し、カットに同期
- `render.mjs` — Playwright でフレームを書き出し、ffmpeg で MP4 にエンコード

## 構成（1小節 = 1.875秒）

| 小節 | 時間 | シーン | 見どころ |
|---|---|---|---|
| 0 | 0.00–1.88 | IGNITION | 点 → 予備動作 → 線に伸びる → スリットが開いて文字が出る → スライス・グリッチ |
| 1 | 1.88–3.75 | TYPE | 拍ごとのキネティック・タイポ「EVERY / SINGLE / FRAME / matters.」 |
| 2 | 3.75–5.63 | FORM | 斜めワイプ → 円・四角・三角・星のモーフ、エコー残像 |
| 3 | 5.63–7.50 | PARTICLES | 約4,600粒子が爆発して「FLOW」を形成し、渦に吸い込まれる |
| 4 | 7.50–9.38 | DEPTH | 2D Canvas上の3D：球 → トーラス → 立方体 → 波打つ面 |
| 5 | 9.38–11.25 | TIMING | ウィップパン → グラフエディタ、ベジェハンドル、オニオンスキン |
| 6 | 11.25–13.13 | SYSTEMS | ボールからのアイリス → 12個のループが同期、1セルへズームイン |
| 7 | 13.13–15.00 | FINALE | インパクト → 「CLAUDE.」 最初の点がピリオドとして戻る |

カメラシェイク・色収差・フィルムグレイン・ビネットは、各ヒットのタイミングで自動的にかかります。

## 再レンダリング

```bash
# ffmpeg（libx264 対応版）と playwright が必要
node render.mjs --mb 4 --workers 4 --out showreel.mp4
```

`--mb` は1フレームあたりのモーションブラーのサブフレーム数、`--frames 300:420` で一部だけ書き出せます。
